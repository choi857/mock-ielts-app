### 接口文档：查询用户所有的主答案列表

#### 1. 接口描述
该接口用于根据用户ID查询用户所有的主答案记录，包括答题的详细信息（如答题时间、得分、设备类型等）以及每个主答案对应的明细答题内容。

---

#### 2. 请求信息

- **请求方法**: `GET`
- **请求路径**: `http://localhost:9485/topic/answers/user/{{userId}}`
userId来自 localStorage.getItem('userId')
- **接口功能**: 查询指定用户的主答案列表及明细答题内容。

---

#### 3. 请求参数

| 参数名称 | 类型   | 是否必填 | 描述           |
|----------|--------|----------|----------------|
| userId   | Long   | 是       | 用户的唯一标识 |

**示例请求路径**:
```
GET /topic/answers/user/12345
```


---

#### 4. 响应信息

##### 4.1 响应格式
- **Content-Type**: `application/json`

##### 4.2 响应参数

响应数据为一个包含用户主答案记录的列表，每个主答案记录包含以下字段：

| 字段名称         | 类型                | 描述                                                                 |
|------------------|---------------------|----------------------------------------------------------------------|
| recordId         | Long                | 主答案记录的唯一标识                                                |
| userId           | Integer             | 用户ID                                                              |
| readingId        | Long                | 阅读题目的唯一标识                                                  |
| score            | Double              | 用户得分                                                            |
| durationSeconds  | Integer             | 答题耗时（秒）                                                      |
| deviceType       | String              | 用户答题时使用的设备类型（如PC、Mobile等）                          |
| createdAt        | Timestamp           | 主答案记录创建时间                                                  |
| updatedAt        | Timestamp           | 主答案记录更新时间                                                  |
| answerEvaluation | String              | 答题评语                                                            |
| readSummaryId    | Long                | 阅读题总表的唯一标识                                                |
| answerDetails    | List<UserAnswerDetailDTO> | 明细答题内容列表，每个明细答题内容包含以下字段：                  |
| - detailId       | Long                | 明细答题记录的唯一标识                                              |
| - recordId       | Long                | 关联的主答案记录ID                                                  |
| - userId         | Long                | 用户ID                                                              |
| - questionId     | Long                | 问题的唯一标识                                                      |
| - answerType     | String              | 答题类型（如FILL_IN_THE_BLANK、MULTIPLE_CHOICE、MATCHING等）        |
| - submittedAnswer| String              | 用户提交的答案                                                      |
| - isCorrect      | Boolean             | 答案是否正确                                                        |
| - blankIndex     | Integer             | 填空题的空格索引（仅适用于填空题，其他类型为null）                  |
| - createdAt      | Timestamp           | 明细答题记录创建时间                                                |

---

#### 5. 错误响应

| HTTP状态码 | 错误码 | 错误信息                     | 描述                           |
|------------|--------|------------------------------|--------------------------------|
| 400        | 400    | Invalid user ID             | 用户ID无效或未提供             |
| 404        | 404    | User not found              | 指定用户不存在                 |
| 500        | 500    | Internal server error       | 服务器内部错误                 |

##### 错误响应示例

```json
{
  "code": 404,
  "message": "User not found",
  "data": null
}
```


---

#### 6. 注意事项
- 如果用户没有任何答题记录，返回的`data`字段将是一个空列表。
- 答题评语（`answerEvaluation`）会根据答题结果动态生成，可能包含多部分内容。
- 明细答题内容中的`blankIndex`字段仅在答题类型为`FILL_IN_THE_BLANK`时有效，其他类型为`null`。
