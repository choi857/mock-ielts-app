### 接口文档

#### 1. 查询用户所有的主答案列表

**接口路径**:
```
GET /topic/answers/user/{userId}
```


**接口描述**:
该接口用于查询指定用户的所有的主答案列表。

**请求参数**:

| 参数名 | 类型   | 是否必填 | 描述         |
|--------|--------|----------|--------------|
| userId | Long   | 是       | 用户ID       |

**响应参数**:

| 参数名          | 类型                | 描述                                                         |
|-----------------|---------------------|--------------------------------------------------------------|
| status          | String              | 成功或失败状态                                               |
| message         | String              | 返回消息                                                     |
| code            | Integer             | HTTP 状态码                                                  |
| data            | List<AnswerRecordDTO>| 返回的数据列表                                               |
| recordId        | Long                | 主答案记录ID                                                 |
| userId          | Integer             | 用户ID                                                       |
| readingId       | Long                | 阅读ID                                                       |
| score           | Double              | 用户得分                                                     |
| durationSeconds | Integer             | 用户答题时长（秒）                                           |
| deviceType      | String              | 设备类型                                                     |
| createdAt       | Timestamp           | 记录创建时间                                                 |
| updatedAt       | Timestamp           | 记录更新时间                                                 |
| answerEvaluation| String              | 答题评语                                                     |
| readSummaryId   | Long                | 阅读题总表ID                                                 |
| answerDetails   | List<UserAnswerDetailDTO>| 用户答题明细列表                                         |

**UserAnswerDetailDTO**:

| 参数名          | 类型    | 描述                                                         |
|-----------------|---------|--------------------------------------------------------------|
| detailId        | Long    | 明细记录ID                                                   |
| recordId        | Long    | 主答案记录ID                                                 |
| userId          | Long    | 用户ID                                                       |
| questionId      | Long    | 问题ID                                                       |
| answerType      | String  | 答题类型                                                     |
| submittedAnswer | String  | 用户提交的答案                                               |
| isCorrect       | Boolean | 用户答案是否正确                                             |
| blankIndex      | Integer | 填空题的空白索引（如果适用）                                 |
| createdAt       | Timestamp| 记录创建时间                                                 |

**示例请求**:
```
GET /topic/answers/user/123
```
