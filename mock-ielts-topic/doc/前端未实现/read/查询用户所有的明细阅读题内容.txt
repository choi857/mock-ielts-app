### 接口文档：获取用户明细答题内容

#### 接口描述
根据主答案表的ID和用户ID，查询用户明细答题的内容，包括答题记录的基本信息和每个题目的详细答题情况。

#### 请求方法
`GET`

#### 请求路径
`http://localhost:9485/topic/answers/user/{{userId}}/record/{{recordId}}`

#### 请求参数
| 参数名    | 类型   | 必填 | 描述               |
|-----------|--------|------|--------------------|
| `userId`  | Long   | 是   | 用户ID             |
| `recordId`| Long   | 是   | 主答案表的ID       |

GET http://localhost:9485/topic/answers/user/26/record/602442757554639803

#### 响应字段说明
| 字段名               | 类型   | 描述                           |
|----------------------|--------|--------------------------------|
| `status`             | String | 请求状态，`success` 表示成功   |
| `message`            | String | 响应消息                       |
| `code`               | Integer| 响应状态码，`200` 表示成功     |
| `data`               | Object | 响应数据                       |
| `data.recordId`      | String | 答题记录ID                     |
| `data.userId`        | Integer| 用户ID                         |
| `data.readingId`     | String | 阅读材料ID                     |
| `data.score`         | Double | 答题得分                       |
| `data.durationSeconds`| Integer| 答题耗时（秒）                 |
| `data.deviceType`    | String | 答题设备类型                   |
| `data.createdAt`     | Long   | 答题记录创建时间（时间戳）     |
| `data.updatedAt`     | Long   | 答题记录更新时间（时间戳）     |
| `data.answerEvaluation`| String | 答题评价                       |
| `data.readSummaryId` | String | 阅读题汇总ID                   |
| `data.answerDetails` | List   | 答题详情列表                   |
| `answerDetails.detailId`| String | 答题详情ID                   |
| `answerDetails.recordId`| String | 关联的答题记录ID             |
| `answerDetails.userId`| String | 用户ID                       |
| `answerDetails.questionId`| String | 题目ID                     |
| `answerDetails.answerType`| String | 题目类型                   |
| `answerDetails.submittedAnswer`| String | 用户提交的答案           |
| `answerDetails.blankIndex`| Integer| 填空题的空白索引（可为空）|
| `answerDetails.createdAt`| Long | 答题详情创建时间（时间戳）|
| `answerDetails.mergedColumn`| String | 正确答案|
| `answerDetails.correct`| Boolean | 答题是否正确               |

#### 注意事项
1. **路径参数**：`userId` 和 `recordId` 必须有效，否则会返回错误。
2. **响应数据**：`answerDetails` 是一个列表，包含每个题目的详细答题情况。
3. **时间戳**：`createdAt` 和 `updatedAt` 是 Unix 时间戳（毫秒级）。

#### 错误响应
如果请求参数无效或记录不存在，可能会返回以下错误：
```json
{
  "status": "error",
  "message": "记录不存在",
  "code": 404,
  "data": null
}
```
