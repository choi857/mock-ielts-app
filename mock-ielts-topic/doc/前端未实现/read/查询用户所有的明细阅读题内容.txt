

### 接口文档：获取用户明细答题内容

#### 1. **接口描述**
根据主答案表的ID (`recordId`) 和用户ID (`userId`) 查询用户详细的答题内容。

#### 2. **请求方式**
`GET`

#### 3. **接口路径**
```
GET http://localhost:9485/topic/answers/record/{{recordId}}/{{userId}}
```


#### 4. **请求参数**
| 参数名   | 类型   | 是否必填 | 描述                     |
|----------|--------|----------|--------------------------|
| recordId | Long   | 是       | 主答案表的ID             |
| userId   | Long   | 是       | 用户ID                   |

#### 5. **返回结果**
- **成功时**：
  - 状态码：`200 OK`
  - 返回数据结构：`ResponseResult<AnswerRecordDTO>`

##### `ResponseResult` 数据结构
```json
{
  "status": "success", // 成功或失败状态
  "message": "操作成功", // 返回消息
  "code": 200, // HTTP 状态码
  "data": { // 返回数据
    "recordId": 1, // 主答案表的ID
    "userId": 101, // 用户ID
    "readingId": 201, // 阅读题目的ID
    "score": 8.5, // 分数
    "durationSeconds": 120, // 答题时长（秒）
    "deviceType": "PC", // 设备类型
    "createdAt": "2023-10-01T12:00:00Z", // 创建时间
    "updatedAt": "2023-10-01T12:05:00Z", // 更新时间
    "answerEvaluation": "良好", // 答案评价
    "readSummaryId": 301, // 阅读摘要ID
    "answerDetails": [ // 答题明细
      {
        "questionId": 401, // 问题ID
        "userAnswer": "正确答案", // 用户答案
        "correctAnswer": "正确答案", // 正确答案
        "isCorrect": true // 是否正确
      }
    ],
    "title": "阅读理解题目标题" // 题目标题
  }
}
```


##### `AnswerRecordDTO` 数据结构
```java
public class AnswerRecordDTO {
    private Long recordId; // 主答案表的ID
    private Integer userId; // 用户ID
    private Long readingId; // 阅读题目的ID
    private Double score; // 分数
    private Integer durationSeconds; // 答题时长（秒）
    private String deviceType; // 设备类型
    private Timestamp createdAt; // 创建时间
    private Timestamp updatedAt; // 更新时间
    private String answerEvaluation; // 答案评价
    private Long readSummaryId; // 阅读摘要ID
    private List<UserAnswerDetailDTO> answerDetails; // 答题明细
    private String title; // 题目标题
}
```


##### `UserAnswerDetailDTO` 数据结构
```java
public class UserAnswerDetailDTO {
    private Long questionId; // 问题ID
    private String userAnswer; // 用户答案
    private String correctAnswer; // 正确答案
    private Boolean isCorrect; // 是否正确
}
```


- **失败时**：
  - 状态码：`500 Internal Server Error`
  - 返回数据结构：`ResponseResult<T>`
  ```json
  {
    "status": "error",
    "message": "操作失败",
    "code": 500,
    "data": null
  }
  ```


#### 6. **示例请求**
```
GET /topic/answers/record/123/456
```

#### 8. **注意事项**
- 如果 `recordId` 或 `userId` 不存在，可能会返回自定义错误信息。
- 返回的 `answerDetails` 列表可能为空，表示该用户未作答或无明细记录。
