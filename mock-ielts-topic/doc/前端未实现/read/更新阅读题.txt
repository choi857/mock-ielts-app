### 接口文档：更新阅读材料及其题目和答案

#### 接口名称
更新阅读材料及其题目和答案

#### 请求方法
`POST`

#### 请求路径
`http://localhost:9485/topic/reading/update`

#### 请求头
- `Content-Type: application/json`

#### 请求体
```json
{
  "readingSummary": {
    "id": "Long", // 阅读材料的ID
    "title": "String", // 阅读材料的标题
    "content": "String" // 阅读材料的内容
  },
  "parts": [
    {
      "id": "Long", // 题目的ID
      "question": "String", // 题目内容
      "answers": [
        {
          "id": "Long", // 答案的ID
          "content": "String", // 答案内容
          "isCorrect": "Boolean" // 是否正确
        }
      ]
    }
  ]
}
```


#### 响应
##### 成功响应
- **状态码**: 200
- **响应体**:
  ```json
  {
    "code": 200,
    "message": "阅读材料更新成功",
    "data": null
  }
  ```


##### 失败响应
- **状态码**: 400 或其他错误状态码
- **响应体**:
  ```json
  {
    "code": 400,
    "message": "更新阅读材料失败，异常为: [异常信息]",
    "data": null
  }
  ```


#### 功能描述
该接口用于更新阅读材料及其相关的题目和答案。更新成功后，会清除相关的缓存数据。

#### 缓存处理
- 清除 `getAllReadingIDs` 缓存。
- 清除 `getReadingWithQuestionsAndAnswers` 缓存，缓存的键为 `readingInsertDTO.readingSummary.id`。

#### 示例
##### 请求示例
```json
{
  "readingSummary": {
    "id": 1,
    "title": "Updated Reading Title",
    "content": "Updated Reading Content"
  },
  "parts": [
    {
      "id": 1,
      "question": "Updated Question",
      "answers": [
        {
          "id": 1,
          "content": "Updated Answer",
          "isCorrect": true
        }
      ]
    }
  ]
}
```


##### 响应示例
```json
{
  "code": 200,
  "message": "阅读材料更新成功",
  "data": null
}
```


#### 注意事项
- 确保传入的 `readingInsertDTO` 数据格式正确。
- 如果更新失败，会返回具体的异常信息。
