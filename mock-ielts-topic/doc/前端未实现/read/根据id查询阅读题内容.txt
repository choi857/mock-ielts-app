### 接口文档：获取阅读材料及其题目和答案

#### 接口名称
获取阅读材料及其题目和答案

#### 接口路径
`GET http://localhost:9485/topic/reading/{{id}}`

#### 请求参数
| 参数名 | 类型   | 必填 | 描述           |
| ------ | ------ | ---- | -------------- |
| id     | Long   | 是   | 阅读材料的 ID  |

#### 响应参数
| 参数名 | 类型               | 描述                           |
| ------ | ------------------ | ------------------------------ |
| code   | Integer            | 响应状态码                     |
| msg    | String             | 响应消息                       |
| data   | ReadingInsertDTO   | 包含阅读材料及其题目和答案的 DTO |

#### ReadingInsertDTO 结构
```java
public class ReadingInsertDTO implements Serializable {
    private ReadingSummaryDTO readingSummary; // 阅读汇总信息
    private List<PartDTO> parts; // 包含阅读材料及其题目和答案的列表
}
```


#### ReadingSummaryDTO 结构
```java
public class ReadingSummaryDTO implements Serializable {
    private Long id; // 阅读汇总 ID
    private String title; // 阅读汇总标题
    private Date createdAt; // 创建时间
    private Date updatedAt; // 更新时间
}
```


#### PartDTO 结构
```java
public class PartDTO {
    private ReadingDTO reading; // 阅读材料信息
    private List<QuestionWrapperDTO> questions; // 题目及其答案列表
}
```


#### ReadingDTO 结构
```java
public class ReadingDTO {
    private Long id; // 阅读材料 ID
    private String title; // 阅读材料标题
    private String content; // 阅读材料内容
    private String imageBase64; // 图片的 Base64 编码
}
```


#### QuestionWrapperDTO 结构
```java
public class QuestionWrapperDTO {
    private QuestionDTO question; // 题目信息
}
```


#### QuestionDTO 结构
```java
public class QuestionDTO {
    private Long id; // 题目 ID
    private String type; // 题目类型
    private String content; // 题目内容
    private String placeholderFormat; // 占位符格式
    private Integer serial; // 题目序号
    private List<AnswerDTO> answers; // 答案列表
}
```


#### AnswerDTO 结构
```java
public class AnswerDTO {
    private Long id; // 答案 ID
    private String content; // 答案内容
    private Boolean correct; // 是否正确
    private Integer blankNumber; // 填空编号
    private String matchingKey; // 匹配键
}
```

#### 错误响应示例
```json
{
    "code": 500,
    "msg": "查询阅读材料失败，异常为: 未找到对应的阅读汇总"
}
```


#### 缓存说明
- 该接口使用了缓存，缓存名称为 `getReadingWithQuestionsAndAnswers`，缓存键为 `#id`，即传入的阅读材料 ID。
