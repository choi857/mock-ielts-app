以下是基于代码编写的接口文档，包含接口描述、请求参数、响应示例等内容。

---

### 接口文档

#### 1. 接口描述
- **接口名称**: 根据用户ID和记录ID查询答题详细信息
- **接口路径**: `http://localhost:9485/topic/writing/answers/user/{{userId}}/record/{{recordId}}`
- **请求方法**: `GET`
- **功能描述**: 根据用户ID和记录ID查询用户的答题详细信息，包括主记录和答题明细。

---

#### 2. 请求参数
| 参数名     | 类型   | 必填 | 描述           |
|------------|--------|------|----------------|
| `userId`   | Long   | 是   | 用户ID         |
| `recordId` | Long   | 是   | 答题记录ID     |

---

---

#### 4. 响应字段说明
| 字段名         | 类型                     | 描述                     |
|----------------|--------------------------|--------------------------|
| `status`       | String                   | 请求状态（`success`/`error`） |
| `message`      | String                   | 返回消息                 |
| `code`         | Integer                  | HTTP状态码               |
| `data`         | WritingAnswerRecordDetailDTO | 返回数据                 |
| `recordId`     | Long                     | 答题记录ID               |
| `userId`       | Long                     | 用户ID                   |
| `task1Id`      | Long                     | 任务1ID                  |
| `task2Id`      | Long                     | 任务2ID                  |
| `createdAt`    | Timestamp                | 创建时间                 |
| `updatedAt`    | Timestamp                | 更新时间                 |
| `totalScore`   | Double                   | 总分                     |
| `details`      | List<WritingAnswerDetail> | 答题明细列表             |
| `detailId`     | Long                     | 答题明细ID               |
| `taskType`     | String                   | 任务类型（如Task 1/Task 2） |
| `answerContent`| String                   | 答题内容                 |
| `answerEvaluation` | String                | 答题评价                 |
| `score`        | Double                   | 得分                     |

---

#### 5. 错误码说明
| 错误码 | 描述                     |
|--------|--------------------------|
| 200    | 请求成功                 |
| 404    | 未找到对应的答题记录     |
| 500    | 服务器内部错误           |

---
