### 接口文档：根据ID获取口语材料

#### 接口描述
该接口用于根据口语材料的ID获取对应的口语材料信息。

#### 请求URL
```
GET http://localhost:9486/speaking/{{id}}
```


#### 请求方法
`GET`

#### 请求参数
| 参数名 | 类型   | 必填 | 描述           |
| ------ | ------ | ---- | -------------- |
| id     | Long   | 是   | 口语材料的唯一标识符 |

#### 请求示例
```
GET /speaking/1
```


#### 响应参数
| 参数名  | 类型          | 描述                     |
| ------- | ------------- | ------------------------ |
| status  | String        | 响应状态，通常为"success" |
| message | String        | 响应消息                 |
| code    | Integer       | HTTP状态码               |
| data    | SpeakingDTO   | 返回的口语材料DTO        |

#### 响应示例
```json
{
    "status": "success",
    "message": "口语材料获取成功",
    "code": 200,
    "data": {
        "speaking": {
            "id": "1",
            "title": "Sample Speaking Title",
            "imageUrl": "http://example.com/image.jpg",
            "transcript": "This is a sample transcript."
        },
        "parts": {
            "part1": [
                {
                    "question": {
                        "id": 1,
                        "speakingId": 1,
                        "type": "question",
                        "content": "What is your favorite color?",
                        "imageUrl": "http://example.com/image.jpg",
                        "createdAt": "2023-01-01T00:00:00",
                        "updatedAt": "2023-01-01T00:00:00",
                        "serial": 1,
                        "part": "part1"
                    }
                }
            ]
        }
    }
}
```


#### 错误响应
| 状态码 | 描述                     |
| ------ | ------------------------ |
| 404    | 未找到对应的口语材料     |
| 500    | 服务器内部错误           |

#### 错误响应示例
```json
{
    "status": "error",
    "message": "未找到对应的口语材料",
    "code": 404,
    "data": null
}
```


#### 备注
- 该接口返回的口语材料DTO包含口语材料的基本信息以及相关的题目部分。
- 如果提供的ID不存在，接口将返回404状态码。
