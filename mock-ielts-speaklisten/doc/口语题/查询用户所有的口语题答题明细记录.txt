
GET http://localhost:9486/speak/userAnswer/user/{{userId}}/record/{{recordId}}/details



#### 4. **请求方法**
`GET`

#### 5. **请求参数**

| 参数名    | 类型   | 必填 | 描述           |
|-----------|--------|------|----------------|
| `userId`  | `Long` | 是   | 用户 ID        |
| `recordId`| `Long` | 是   | 答题记录 ID    |

- **状态码**: `404` 或其他错误状态码
- **响应体**:
  ```json
  {
    "status": "fail",
    "message": "未找到对应的答题记录",
    "code": 404,
    "data": null
  }
  ```


#### 7. **响应字段说明**

| 字段名                     | 类型      | 描述                     |
|----------------------------|-----------|--------------------------|
| `status`                   | `String`  | 请求状态（`success` 或 `fail`） |
| `message`                  | `String`  | 响应消息                 |
| `code`                     | `Integer` | 状态码                   |
| `data`                     | `Object`  | 返回的答题详细信息       |
| `data.SpeakUserAnswerRecord`| `Object`  | 答题主记录（当前为 `null`） |
| `data.parts`               | `Map`     | 按部分分类的答题明细     |
| `data.parts.Part1`         | `List`    | Part1 的答题明细列表     |
| `data.parts.Part2`         | `List`    | Part2 的答题明细列表     |
| `data.parts.Part3`         | `List`    | Part3 的答题明细列表     |
| `data.parts.PartX.answer`  | `Object`  | 单个答题明细             |
| `answer.detailId`          | `String`  | 答案明细 ID              |
| `answer.recordId`          | `String`  | 关联的答题记录 ID        |
| `answer.userId`            | `Integer` | 用户 ID                  |
| `answer.questionId`        | `String`  | 关联的题目 ID            |
| `answer.userAudioUrl`      | `String`  | 用户回答的音频 URL       |
| `answer.userTranscript`    | `String`  | 用户回答的文本转录       |
| `answer.score`             | `String`  | 用户回答的得分           |
| `answer.feedback`          | `String`  | 用户回答的评价和反馈     |
| `answer.createdAt`         | `String`  | 答题提交时间             |
| `answer.part`              | `String`  | 题目所属部分             |
| `answer.questionContent`   | `String`  | 题目内容                 |
