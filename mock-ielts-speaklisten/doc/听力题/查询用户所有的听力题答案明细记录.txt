### 接口文档

#### 接口名称
根据 `recordId` 和 `userId` 查询答题详细信息

#### 请求地址
`GET http://localhost:9486/topic/listening/answers/user/{{userId}}/record/{{recordId}}`

#### 请求参数
| 参数名    | 类型   | 必填 | 描述         |
|-----------|--------|------|--------------|
| `userId`  | Long   | 是   | 用户ID       |
| `recordId`| Long   | 是   | 答题记录ID   |

#### 响应示例
**成功响应：**
```json
{
    "code": 200,
    "message": "成功",
    "data": [
        {
            "detailId": 1,
            "recordId": 123,
            "userId": 26,
            "questionId": 456,
            "createdAt": "2023-10-01T12:00:00",
            "part": "Part1",
            "submittedAnswer": "Sample Answer",
            "mergedColumn": "Sample Placeholder or Matching Key"
        },
        {
            "detailId": 2,
            "recordId": 123,
            "userId": 26,
            "questionId": 789,
            "createdAt": "2023-10-01T12:05:00",
            "part": "Part2",
            "submittedAnswer": "Another Answer",
            "mergedColumn": "Another Placeholder or Matching Key"
        }
    ]
}
```


**失败响应：**
```json
{
    "code": 404,
    "message": "未找到对应的答题记录",
    "data": null
}
```


#### 响应字段说明
| 字段名         | 类型   | 描述                           |
|----------------|--------|--------------------------------|
| `code`         | Integer| 状态码，200 表示成功，404 表示未找到记录 |
| `message`      | String | 响应消息                       |
| `data`         | List   | 答题详细信息列表，可能为空      |
| `detailId`     | Long   | 答题详情ID                     |
| `recordId`     | Long   | 答题记录ID                     |
| `userId`       | Long   | 用户ID                         |
| `questionId`   | Long   | 题目ID                         |
| `createdAt`    | String | 创建时间                       |
| `part`         | String | 题目所属部分（如 Part1, Part2）|
| `submittedAnswer` | String | 用户提交的答案               |
| `mergedColumn` | String | 合并字段（占位符或匹配键）     |

#### 注意事项
1. 如果未找到对应的答题记录，返回状态码 `404` 和提示信息。
2. `data` 字段为 `List<ListeningUserAnswerCorrectDetail>` 类型，包含多个答题详细信息。
3. `mergedColumn` 字段的值由 `COALESCE` 函数生成，可能是占位符、匹配键或其他默认值。
