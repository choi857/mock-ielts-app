### 接口文档：查询听力题目及答案

#### 接口描述
该接口用于根据听力材料的ID查询对应的听力题目及答案信息。

#### 请求URL
```
GET http://localhost:9486/listening/admin/getListeningWithQuestionsAndAnswers/{{listeningId}}
```


#### 请求方法
`GET`

#### 请求参数
| 参数名      | 类型   | 必填 | 描述           |
| ----------- | ------ | ---- | -------------- |
| listeningId | Long   | 是   | 听力材料的唯一标识符 |

#### 请求示例
```
GET /listening/admin/getListeningWithQuestionsAndAnswers/1
```


#### 响应参数
| 参数名  | 类型          | 描述                     |
| ------- | ------------- | ------------------------ |
| status  | String        | 响应状态，通常为"success" |
| message | String        | 响应消息                 |
| code    | Integer       | HTTP状态码               |
| data    | Object        | 返回的听力题目及答案信息 |

#### 响应示例
```json
{
    "status": "success",
    "message": "听力题目及答案获取成功",
    "code": 200,
    "data": {
        "listening": {
            "id": 1,
            "title": "Sample Listening Title",
            "audioUrl": "http://example.com/audio.mp3"
        },
        "questions": [
            {
                "id": 1,
                "listeningId": 1,
                "type": "multiple_choice",
                "content": "What is the main topic of the conversation?",
                "options": [
                    "Weather",
                    "Sports",
                    "Politics"
                ],
                "correctAnswer": "Weather"
            }
        ]
    }
}
```


#### 错误响应
| 状态码 | 描述                     |
| ------ | ------------------------ |
| 404    | 未找到对应的听力材料     |
| 500    | 服务器内部错误           |

#### 错误响应示例
```json
{
    "status": "error",
    "message": "未找到对应的听力材料",
    "code": 404,
    "data": null
}
```


#### 备注
- 该接口返回的听力题目及答案信息包含听力材料的基本信息以及相关的题目和答案。
- 如果提供的ID不存在，接口将返回404状态码。
- 该接口使用了缓存机制，缓存名称为`getListeningWithQuestionsAndAnswers`，缓存键为`listeningId`。
