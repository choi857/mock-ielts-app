
### 2. 删除文件

- **URL**: `DELETE http://localhost:9489/files/{fileName}`
- **Description**: 删除指定文件。
- **Method**: `DELETE`
- **Path Parameters**:
  - `fileName` (required): 文件名，类型为 `String`。
- **Response**:
  - **Status Code**: `200 OK`
    - **Description**: 文件删除成功。
    - **Response Body**:
      ```json
      {
        "status": "success",
        "message": "文件删除成功",
        "code": 200,
        "data": null
      }
      ```

  - **Status Code**: `500 Internal Server Error`
    - **Description**: 文件删除失败。
    - **Response Body**:
      ```json
      {
        "status": "error",
        "message": "文件删除失败: 错误信息",
        "code": 500,
        "data": null
      }
      ```
